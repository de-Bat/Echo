# Price Tracker App

This application helps track item prices from various online shops,
estimates the best time to buy using AI-driven predictions, and
provides recommendations.

## Features (Planned)

- Price scraping from multiple online stores.
- Historical price tracking.
- AI-powered purchase timing recommendations.
- Consideration of shipping and taxes for multiple user-defined addresses.
- Recommendation accuracy and certainty ranking.
